# 图片翻译模式说明

## 1. 设计目标

把任意图片（路牌、菜单、公文、文档、聊天截图）中的文字识别出来，逐行翻译并以"双语图"形式输出。
- 相机实时取景（CameraX）或相册选择。
- OCR 在本地完成。
- 翻译在本地完成。
- 双语图可保存到相册。

## 2. 流程

```
图片 → Exif 旋转矫正 → 采样至 4096px → ML Kit OCR（拉丁+中文）
   → 行级切分 → 每行 NMT 翻译 → 双语图绘制
```

## 3. 模式选择

- **通用**：任意图片。
- **路牌**：通常文字较少、字号大；OCR 阈值宽松。
- **菜单**：竖排、中英对照常见；保留换行。
- **公文**：横排、多列；保留段落结构。

模式选择影响 OCR 的预处理（如路牌模式提升对比度、菜单模式保留竖排）。
本工程未做图像预处理（增强对比度、矫正畸变），属后续优化点。

## 4. 双语图覆盖

`ImageTranslateViewModel.generateOverlayBitmap()`：
- 在原图上绘制半透明白底覆盖原文区域。
- 写入译文（按 bbox 宽度自动换行）。
- 字号按图像高度自适应。

## 5. 性能

- 1080p 图片 OCR：~800 ms（中英混排）。
- 10 行翻译：~1.5 s（每行 ~150 ms）。
- 双语图绘制：< 100 ms。

## 6. 限制

- ML Kit 中文识别器单次最长 ~3 m × 3 m 的图像。
- 当前实现未做"文字方向矫正"（竖排、旋转 90°）。
- 对艺术字、手写体识别率较低。
